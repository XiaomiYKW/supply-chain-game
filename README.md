# 供应链模拟游戏教学辅助系统

专为课堂教学设计的多用户供应链经营模拟游戏：**学生决策经营、教师全班控参、期末匿名排名导出**。
支持「全班同月实际需求完全一致」的公平性机制，保证课堂横向对比有意义。

---

## 一、系统功能总览

### 👩‍🎓 学生端
- 每月提交 4 项决策：**需求预测、生产数量、供应商1采购（长交期便宜）、供应商2采购（当月到货应急）**
- 提交后自动结算下月：生成实际需求 → 计算销量/成本/利润 → 推导下月现金与库存
- 报告页查看：销售收入、成本拆分（6 项）、本月利润、累计利润、历史趋势图、班级匿名排名与利润差对比

### 👨‍🏫 教师端（核心教学功能）
1. **全班重置**：清空所有学生历史数据（保留学生账号与教师参数设置），同步所有学生回到「第 1 月初始状态」开新一轮
2. **匿名排名 Excel 导出**：期末一键导出全班 xlsx（只以"排名"标识，**无姓名/学号/ID**），包含 3 张表：
   - Sheet1：全班排名汇总（累计利润、已完成月数等）
   - Sheet2：各月利润明细（按排名展开每个学生每月利润）
   - Sheet3：各月「预测 vs 实际」对比（偏差 >30% 自动标红）
3. **学生管理**：列表查看全班进度、单生历史明细、批量导入学生账号、重置单个学生进度
4. **需求模式二选一**（全班同月实际需求一致，保证公平）：
   - **模式一 · Excel 导入**：教师上传每月基准需求表 → 按设定波动区间生成当月实际需求
   - **模式二 · 曲线预设（推荐教学，默认）**：提供 6 种教学常见曲线（正弦季节波、牛鞭效应、经济周期繁荣崩盘、促销脉冲、线性增长、平稳恒定）× 3 档快捷强度，一键写入并预览趋势图
5. **22+ 参数动态调节**（全部在教师端 Tab3 可视化修改，无需写代码）：
   - 价格与产能：销售单价、供应商1/2单价与交期、工厂产能
   - 仓库容量：原料仓/成品仓上限
   - 成本体系：原料/成品持有成本、原料/成品超额成本
   - 难度惩罚：固定成本（每月）、缺货惩罚（每个缺货）、负现金利息率
   - 初始设置：初始现金、初始原料库存、初始成品库存
   - 游戏周期：总月数（默认 12 月，教师可调）
   - 需求波动区间：基准 × [下限, 上限]（用于 Excel 导入模式或曲线模式的波动）
   - 需求种子 `demand_seed`：全班同月实际需求完全一致的公平性保证（同种子 + 同月 → 同一波动因子）

## 三、快速开始（本地运行，教师/维护者自测）

### 3.1 启动后端（API 服务，端口 8005）
```bash
cd backend
pip install -r requirements.txt
# 方式一：直接跑（FastAPI）
python main.py
# 方式二：标准 uvicorn
uvicorn main:app --reload --port 8005 --host 0.0.0.0
```
- 默认数据库：`backend/game.db`（SQLite，首次启动自动建表 + 补列）
- 接口文档：`http://127.0.0.1:8005/docs`（Swagger UI 在线调试）
- 初始化教师账号（若不存在）：`python create_teacher.py` 生成 `teacher1 / 123`

### 3.2 启动前端静态页（端口 8080）
直接双击 HTML 可能被浏览器本地文件限制，建议用 Python 简易服务器：
```bash
# 在项目根目录执行
python -m http.server 8080 --bind 127.0.0.1
```

### 3.3 浏览器访问
- 登录入口：`http://127.0.0.1:8080/index.html`
- 教师登录：`teacher1 / 123`（或你自己创建的教师账号）
- 学生登录：教师端 Tab1「学生管理」批量导入后，用学生账号登录（例 `zhang_san / 123456`）

## 四、教师端操作手册（教学流程全解）

> 建议教学流程：**开课前创建学生账号 → 设置需求模式 + 难度参数 → 告诉全班本论曲线/基准 → 每轮结束点"重置全班" → 期末导出匿名排名**

### Tab1｜学生管理
| 按钮 | 功能 |
|---|---|
| 🔽 下载导入模板 | 获取 xlsx 模板（列：`username, password, display_name`） |
| 📥 批量导入学生 Excel | 上传填好的 xlsx，批量创建学生账号（已存在同名账号会跳过） |
| 🗑️ 删除单个学生 | 删除某学生账号 + 该生所有历史决策 |
| 🔄 重置单个学生 | 清空某学生历史、直接回到第 1 月初始状态（保留账号密码） |
| 👁️ 查看详情 | 看某学生每月决策明细与累计利润趋势 |
| ⬇️ 导出学生名单 xlsx | 导出全班账号清单（有密码，建议教师自用别外传） |

### Tab2｜全班操作（常用）
| 按钮 | 功能 |
|---|---|
| 🔴 **重置全班游戏**（二次确认） | 清空所有学生全部月决策数据，但**保留**：学生账号密码、你在 Tab3 设的参数、Tab4 选的需求模式与曲线/基准表。清空后每个学生自动重建「第 1 月初始状态」——现金/原料/成品全部用你 Tab3 设的初始值。适合每轮结束开新一轮 |
| 🟢 **导出匿名排名 Excel** | 下载 xlsx，**严格匿名**（第一列只有排名，无姓名/学号/用户ID），包含 3 张表：<br>① 排名汇总 ② 各月利润明细（按排名 × 月份网格） ③ 各月「预测 vs 实际」对比（偏差绝对值>30% 标红） |

### Tab3｜参数与难度设置（22+ 全部可改）
- 分 5 组卡片：**价格与交期 / 仓库容量 / 成本规则 / 难度惩罚 / 初始设置与波动区间**
- 改完点对应组卡片下方的「💾 保存 ×× 参数」，立即生效（不影响已结算月份）
- **总月数（`game_total_months`）**：默认 12，可改 6/10/15 等；玩到第 `N` 月后自动封盘（不能再提交决策）

### Tab4｜需求模式（全班公平性核心）
> 两个模式**二选一**，保存后对全班同月一致（实际需求完全相同，保证横向排名有意义）

#### 🔘 模式一 · Excel 导入每月基准需求
1. 点「下载 Excel 模板」→ 填每个月（1-N 月）的"基准需求量"
2. 点「选择 Excel 导入」→ 导入后下方表格可直接再手动改每个月的值
3. 改完点「💾 保存表格修改」持久化

#### 🔘 模式二 · 曲线预设生成基准需求（推荐教学，默认）
1. **曲线类型**（6 种）：
   | 曲线 | 适用教学场景 |
   |---|---|
   | `flat` 平稳恒定 | 入门班，先教会流程 |
   | `sine` 正弦季节波 | 冷饮/服装等季节性商品 |
   | `linear_growth` 线性增长 | 新品爬坡期 |
   | `boom_bust` 经济周期 | 先繁荣后崩盘（宏观经济学） |
   | `bullwhip` 牛鞭效应 | 噪声逐月放大，经典供应链 |
   | `promo_pulse` 促销脉冲 | 电商大促节奏（平稳 + 峰值） |
2. **波动强度 3 档快捷按钮**：弱 / 中 / 强（自动填好波动区间上下限，可手动再调）
3. 点「📈 生成并预览曲线」→ 下方出现折线图看 1-N 月趋势，满意再点「💾 写入全班需求基准」

### Tab5｜班级排名监控
- 实时全班累计利润降序排名（相同利润按「已完成月数多者赢」）
- 点「刷新排名」手动拉最新数据
- 绿条第一、黄条倒数后三，方便上课快速点名分析

## 五、学生端操作手册（每月玩法）

每月固定 3 步（教师公布本月曲线/基准后开始）：

### Step1｜看月初状态（决策页左侧）
- 现金、原料库存、成品库存、供应商1/2单价与交期、工厂产能、成本规则表
- 右上角显示：第 **X / N** 月（N 是教师设置的总月数，默认 12）

### Step2｜填本月决策（右侧 4 个数字框，提交后不能改）
| 输入项 | 说明 |
|---|---|
| 📊 需求预测 | 仅做你自己的决策记录（不影响系统实际需求，是教师对比你的判断准确度用） |
| 🏭 生产数量 | 原料 1:1 出成品，受「本月可用原料 + 工厂产能」双约束 |
| 📦 供应商1采购 | 便宜、交期长（默认 1 月后到货，即下个月才能用这批货生产）|
| 🚨 供应商2采购 | 贵、当月到货应急（本月下单可用于本月生产，现金不够会优先保供应商2，再保供应商1） |

> ⚠️ 提交后**自动结算当月并进入下一月**，决策不可撤回。

### Step3｜看结算报告（跳转报告页）
- 销售结果：**你的预测需求 / 系统实际需求 / 销售收入**
- 成本与利润拆分：总成本 / 采购 / 持有 / 超额 / 固定 / 缺货 / 利息 / 本月利润 / 累计利润
- 历史趋势：累计利润、收入、成本曲线
- 我的班级排名：当前名次、与第一名累计利润差、第一名累计利润与已玩月数
- 对比趋势：我的累计利润 vs 当前第一名累计利润叠加对比
- 月度明细表格：逐月所有数字（已结算月份）

## 六、游戏核心规则（完整公式，教师备课用）

> 所有规则均在 `backend/game_logic.py` 实现，可代码溯源。

### 6.1 公平性机制（关键）
**全班同月实际需求一字不差**，实现方式：
- 教师在 `game_config` 保存全局 `demand_seed`（整数）
- 同一 `demand_seed` + 同一月份 `month` → 数学上固定同一个「波动因子」
- 实际需求 = 本月基准需求（来自 Excel 或曲线）× 该固定波动因子 × 夹紧到波动区间
- 因此即使两个学生分别在不同时刻提交，只要是同一个月，最终 `actual_demand` 完全一致

### 6.2 每月结算时序（严格顺序）
```
月初状态 → 到货 → 生产 → 实际需求生成 → 销售 → 扣成本 → 算利润 → 进入下月
```
详细步骤：
1. **供应商到货**：供应商1在途货到（上月采购的本月才到）；供应商2本月采购的货直接当月到
2. **生产执行**：原料 = 月初原料 + 供应商2当月到的货，按 `min(本月可用原料, 工厂产能, 填的计划生产量)` 实际产出成品
3. **实际需求生成**（公平性保证）：已封盘月份不会重算
4. **销售执行**：`实际销量 = min(可用成品, 实际需求)`；销售收入 = 实际销量 × 售价
5. **计算本月全部成本**（见 6.3）
6. **本月利润 = 销售收入 − 本月总成本**；累计利润累加
7. **月底库存**：原料 = 月初 + 到的 − 生产耗的；成品 = 月初 + 实际生产的 − 卖掉的
8. **现金**：月初现金 + 收入 − 所有成本支出（若负则计算负现金利息）

### 6.3 成本构成 6 项（报告页会拆分展示）
| 成本项 | 公式（教师讲解用） |
|---|---|
| ① 采购成本 | `供应商1采购量 × 单价 + 供应商2采购量 × 单价` |
| ② 库存持有成本 | `月底原料库存 × 原料持有费 + 月底成品库存 × 成品持有费` |
| ③ 超仓超额成本 | `max(0, 月底原料库存-原料仓上限) × 原料超额费 + max(0, 月底成品库存-成品仓上限) × 成品超额费` |
| ④ 固定成本（每月） | 教师在 Tab3 设定的 `fixed_cost_per_month`（默认 4000/月） |
| ⑤ 缺货惩罚 | `max(0, 实际需求 − 实际销量) × 缺货惩罚单价`（需求满足不了每缺 1 个罚多少）|
| ⑥ 负现金利息 | `max(0, −月初现金) × 负现金利息率`（现金流紧张就亏） |
| **合计：总成本 = ① + ② + ③ + ④ + ⑤ + ⑥** | |

### 6.4 胜负判定（期末排名）
全班学生按以下**优先级双条件排序**导出排名：
1. 第一关键字：**累计总利润降序**（越高越好）
2. 第二关键字（利润相同时）：**已完成月数多者赢**（没封盘就爆仓出局的算劣势）

## 七、常见教学问答

**Q1：为什么学生端看不到需求曲线/基准数值？**
A：故意设计成**教师口头公布**，锻炼学生课堂听课 + 自己做判断 + 自己记录预测，避免系统给提示弱化教学效果。

**Q2：如何保证全班对比公平？**
A：① `demand_seed` 保证同月实际需求完全相同；② 教师统一选择「Excel 导入」或「曲线预设」后的基准也一致；③ 难度、成本、仓库等参数全班统一配置。

**Q3：学生乱填大数字（如填 999999 生产）怎么办？**
A：系统会自动按「原料上限 + 工厂产能 + 现金约束」裁剪调整，不会真按 999999 算，学生不会因为手滑填错导致爆仓。

**Q4：学期末要保存成绩，怎么操作最稳？**
A：先「🟢 导出匿名排名 Excel」把成绩表存好（归档），再在 Neon/本地数据库做一次备份，最后再点「🔴 重置全班游戏」开下一轮。

**Q5：为什么学生报告页看不到「预测偏差率」和「实际销售」？**
A：为避免学生被系统提示框"带着走"，这些解释性提示在学生端刻意弱化，**所有分析引导应来自教师课堂讲解**，让学生自己对照累计利润与趋势图思考缺货/积压原因。
